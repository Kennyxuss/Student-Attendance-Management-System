# Purpose of AI Use

AI (ChatGPT) was used as a brainstorming and review tool during the planning phase of the Attendance Management System. AI assisted the team in identifying missing CRUD operations, suggesting additional screen states, reviewing the project scope, and improving the clarity of user stories.

All final decisions regarding the project scope, backlog, and wireframes were made by the team.

---

# Prompts Used

### Prompt 1
> Create CRUD user stories for an Attendance Management System.

**Purpose**
To generate Create, Read, Update, and Delete user stories for Students, Teachers, Subjects, Attendance, Reports, and Authentication.

---

### Prompt 2
> Suggest acceptance criteria for each user story.

**Purpose**
To create testable acceptance criteria that will later be used during testing.

---

### Prompt 3
> List every screen required for an Attendance Management System.

**Purpose**
To ensure that no required interface was missed.

---

### Prompt 4
> What empty states and error states should our Attendance Management System include?

**Purpose**
To identify additional UI states required by the project specification.

---

### Prompt 5
> Is this project realistic for five students to complete in ten weeks?

**Purpose**
To evaluate whether the project scope was achievable within the available time.

---

# AI Suggestions Accepted

The team accepted the following AI recommendations:

- CRUD user stories for every record type.
- Separate List View and Detail View user stories.
- Login and Logout features.
- Attendance Reports.
- Acceptance criteria for every user story.
- Empty State screens.
- Error State screens.
- Delete Confirmation screens.

These suggestions improved the completeness of the project backlog.

---

# AI Suggestions Rejected

The team decided not to include the following suggestions because they would increase the project scope beyond what could reasonably be completed within ten weeks:

- QR Code Attendance
- Facial Recognition
- Fingerprint Authentication
- SMS Notifications
- Email Notifications
- Mobile Application
- AI Attendance Prediction
- Cloud Synchronization
- GPS Attendance Verification
- Parent Portal

These features may be considered for future versions of the system.

---

# Reflection

Using AI helped the team organize ideas, identify missing CRUD operations, improve the backlog, and ensure every required screen and state was included.

Although AI provided useful suggestions, the team carefully reviewed each recommendation and only accepted features that aligned with the project requirements and timeline. The final design, backlog, and wireframes are the result of the team's own planning and decision-making.

---

# Conclusion

AI served as a planning assistant rather than a replacement for the team's work. It improved productivity during the scoping phase while allowing the team to maintain control over the project's scope and design decisions.
